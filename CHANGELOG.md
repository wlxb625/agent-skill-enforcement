# Changelog

## 0.3.0-draft

- refocused ASEP on making agents follow Skill requirements during generation;
- restored the standard Agent Skills structure as the universal package model;
- removed `EXECUTION.yaml` and custom top-level directories from the core profile;
- added optional `references/adherence.yaml`;
- added requirement levels, prohibited substitutions, task interpretation, requirement persistence, drift review, and targeted revision;
- moved workflow state, gates, and receipts to an optional advanced extension;
- replaced lifecycle-first examples with minimal and web-design adherence examples;
- rewrote the validator and schema around standard Skill compatibility.

## 0.2.0-draft

- introduced the Agent Skill Enforcement and ASEP names;
- explored lifecycle enforcement, stage locks, gates, and completion control.

## 0.1.0-draft

- initial experiment under the former Contract Skills name.
