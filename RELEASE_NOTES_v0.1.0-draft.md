# Contract Skills Specification 0.1 Draft

This is the first public draft of Contract Skills, an experimental execution-contract extension for portable Agent Skills.

## Included

- bilingual project README;
- draft specification;
- immutable, adaptive, task, and model-local policy hierarchy;
- stage and transition declarations;
- validator, evaluator, and gate separation;
- applicability and repair contracts;
- evaluation attestation levels;
- completion receipt schema;
- Python reference validator and CLI;
- GitHub Actions conformance workflow;
- minimal generic example;
- film-director domain profile example.

## Important limitation

This draft can verify package structure, references, policy boundaries, stage graphs, gate definitions, and completion requirements. It does not claim that semantic evaluators are always honest or independent. Strong semantic guarantees require host-side evaluator isolation or human review.

## Status

Experimental. Breaking changes are expected before 1.0.
