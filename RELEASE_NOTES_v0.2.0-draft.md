# Agent Skill Enforcement Protocol (ASEP) 0.2 Draft

This breaking draft renames the project and centers its actual purpose: enforcing Skill lifecycle obligations rather than merely describing an execution contract.

## Included

- stage locks and required artifacts;
- deterministic validators and semantic evaluators;
- blocking `PASS / CONDITIONAL / FAIL` gates;
- declared repair and return routes;
- protected enforcement rules and bounded adaptation;
- receipt-backed `ASEP_COMPLETE` finalization;
- JSON Schemas, Python validator, tests, and two examples;
- bilingual documentation.

## Migration

See `docs/migration-from-contract-skills.md` for the 0.1 draft mapping.

## Limitation

ASEP can enforce deterministic lifecycle conditions but cannot prove semantic evaluator independence without host support or human verification.
