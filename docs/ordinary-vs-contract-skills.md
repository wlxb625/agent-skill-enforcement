# Ordinary Skills vs Contract Skills

Ordinary Agent Skills are optimized for portable procedural knowledge. Contract Skills keep that portability but add explicit execution semantics.

The difference is not “more prompt text.” A long `SKILL.md` can still be selectively followed. A Contract Skill separates:

- instructions from state;
- preferences from protected rules;
- validation from semantic evaluation;
- evaluation from transition authority;
- draft output from verified completion.

Contract Skills should be used when skipping or reinterpreting a professional process materially harms the result. They are less useful for lightweight inspiration, casual ideation, or tasks where strict lifecycle overhead outweighs the benefit.
