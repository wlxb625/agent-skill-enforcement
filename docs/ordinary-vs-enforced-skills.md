# Ordinary Skills vs ASEP Enforced Skills

Ordinary Agent Skills package reusable procedural knowledge. ASEP Enforced Skills preserve that portability but add lifecycle rules that can block progression and completion.

The difference is not “more prompt text.” A long `SKILL.md` is still guidance unless a runtime owns stage state, validation, gates, repair routes, and finalization.

Use ASEP when skipping or reinterpreting a professional process can materially damage the result. Do not add enforcement overhead to lightweight inspiration, casual ideation, or tasks where advisory instructions are sufficient.

| Question | Ordinary Skill | ASEP Enforced Skill |
|---|---|---|
| Can the model skip a stage? | Often yes | L2/L3 can reject it |
| Can a failed review be ignored? | Often yes | Gate blocks transition |
| Can thresholds be lowered mid-task? | Prompt-dependent | Protected paths forbid it |
| Who decides completion? | Usually the model | Runtime validates receipt |
