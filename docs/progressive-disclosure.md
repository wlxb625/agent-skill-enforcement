# Progressive disclosure

Keep `SKILL.md` focused enough to remain active in context. Put detailed domain material in `references/` and link it directly from `SKILL.md`.

Recommended split:

- `SKILL.md`: activation, core requirements, prohibited patterns, application, review, revision;
- `references/core-requirements.md`: deeper explanation and edge cases;
- `references/quality-criteria.md`: review questions and examples;
- `references/anti-patterns.md`: default failures and false substitutes;
- `scripts/`: deterministic helpers;
- `assets/`: templates and reusable resources.

Do not hide an essential requirement several links deep. Required references should be directly reachable from `SKILL.md`.
