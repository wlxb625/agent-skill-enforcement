# Review and revision

Review should answer whether the output follows the Skill, not whether the agent can describe the Skill.

## Review targets

- visual work: rendered states, layout, motion, hierarchy, responsive behavior;
- writing: complete text, character decisions, causal structure, dialogue, ending;
- code: actual implementation, tests, interfaces, runtime behavior;
- research: claims, sources, analysis, uncertainty, omitted evidence.

## Revision rules

A good revision instruction identifies:

- which requirements failed;
- what must change;
- what already works and should be preserved;
- what should be reviewed again after the change.

Avoid asking the agent to regenerate the entire artifact when only a few requirements drifted.
