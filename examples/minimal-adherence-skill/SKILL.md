# Concise Project Brief

## Required references

Before drafting, read:

- `references/core-requirements.md`
- `references/quality-criteria.md`
- `references/anti-patterns.md`

## Core requirements

- Separate confirmed facts from assumptions.
- State the intended outcome and current constraints.
- Do not invent missing dates, owners, budgets, or technical decisions.
- Keep unresolved questions visible instead of silently resolving them.

## How to apply this Skill

Translate the core requirements into the current project context before drafting. Keep them active while revising the brief.

## Review and revision

Compare the completed brief with `references/quality-criteria.md`. Revise any section that hides uncertainty, mixes facts with assumptions, or adds unsupported detail.
